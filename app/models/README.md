# Bundled character models

Each `<language>.json` holds pruned character n-gram counts (orders 1–4, with
`^` start padding and `$` word end). No word list is stored. Rebuild with
`scripts/build_language_models.py`.

- `en.json`: Webster's Second International word list, as distributed in
  `/usr/share/dict/web2` (public domain; the 1934 copyright has lapsed).
- `fi.json`: Kotus, *Nykysuomen sanalista* 2024, licensed under
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Counts include
  regular case endings generated by the build script; this is a derived work
  and not endorsed by Kotus.

- `nl.json`: OpenTaal Dutch word list (https://github.com/OpenTaal/opentaal-wordlist),
  under the Revised BSD License and/or CC BY 3.0; see `OPENTAAL-LICENSE.txt`.
  Diacritics are removed before counting because puzzles use A–Z.
- `sv.json`: SALDO full-form lexicon (saldom.xml), Språkbanken Text, University
  of Gothenburg, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
  (https://spraakbanken.gu.se/en/resources/saldom). Compound-only parts and
  multi-word entries are excluded. Derived counts, not endorsed by Språkbanken.
