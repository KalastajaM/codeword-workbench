# Getting dictionaries

Codeword Workbench ships only small demonstration word lists and letter-pattern models
(`app/models/`, counts only, no word lists). Real puzzles need a full word list
for each language you solve. This page lists free sources and how to turn each
into the import format.

## Import format

- UTF-8 text, one word per line. A byte-order mark is accepted.
- At most 1,000,000 lines and 16 MB per file.
- Words are uppercased (NFC) and deduplicated on import. A line with any
  character outside the language's alphabet is skipped and counted, not
  repaired: spaces, hyphens, digits and apostrophes all disqualify a line.
- Alphabets: English and Dutch A–Z; Finnish and Swedish A–Z plus Å, Ä, Ö.

Import in the app with **Edit language dictionary → Bulk edit and import**,
choose the file, then **Save dictionary**. The list is stored in
`data/dictionaries/<language>.json` and replaces the previous one for that
language. Include inflections, compounds and names you want found: the solver
matches whole written forms.

Keep each source's licence notice with your downloaded copy. These lists are
not redistributed by this project.

## English

Webster's Second International (1934, public domain) is preinstalled on macOS
and many Linux systems as `/usr/share/dict/web2` (or `words`). It has no
inflected forms, so plurals and verb forms are missing.

Import `/usr/share/dict/web2` directly. Any other one-word-per-line list (for
example a SCOWL/aspell export) works the same way.

## Finnish

| Source | Licence | Download |
| --- | --- | --- |
| Kotus Nykysuomen sanalista 2024 (tab-separated) | CC BY 4.0 | <https://kaino.kotus.fi/lataa/nykysuomensanalista2024.txt> |
| Kotus nykysuomen sanalista v1, 2006 (XML) | GNU LGPL | <https://kaino.kotus.fi/sanat/nykysuomi/> |
| Joukahainen, Voikko project (XML) | GNU GPL 2+ | <https://joukahainen.puimula.org/sanastot/joukahainen.xml.gz> (gunzip first) |

The files are not one word per line, so combine them with:

```sh
python3 scripts/build_finnish_dictionary.py \
    --kotus2024 nykysuomensanalista2024.txt \
    --kotus2006 kotus-sanalista_v1.xml \
    --joukahainen joukahainen.xml \
    -o finnish.txt
```

Any subset of the three works. All three together give about 118,000 words.
These are headwords: inflected forms come from the optional morphology index
below.

### Optional: inflected Finnish forms

Finnish puzzles are full of case endings that no headword list contains. The
app can search a local form index generated by Omorfi from the Kotus 2024
list. It needs native HFST and Python 3.12:

1. Download the Omorfi 0.9.12 model archive from
   <https://github.com/flammie/omorfi/releases/tag/v0.9.12> and extract
   `omorfi.analyse.hfst` and `omorfi.generate.hfst` into `data/morphology/`.
2. Build the index:

   ```sh
   python3.12 -m venv data/morphology/native
   data/morphology/native/bin/python -m pip install hfst==3.16.0.1
   data/morphology/native/bin/python scripts/build_finnish_morphology.py \
       --source /path/to/nykysuomensanalista2024.txt
   ```

3. In the app, enable **Use dictionary**, then **Local inflected words**.

The builder writes `data/morphology/fi.sqlite` and a `build-report.json` with
checksums and coverage. Do not substitute `pyhfst`: it omits valid forms.

## Dutch

The OpenTaal word list (Revised BSD and/or CC BY 3.0):
<https://github.com/OpenTaal/opentaal-wordlist>, file `wordlist.txt`
(direct: <https://raw.githubusercontent.com/OpenTaal/opentaal-wordlist/master/wordlist.txt>).

It imports directly, but entries with accents (IDEEËN, CAFÉ) are skipped
because Dutch puzzles use A–Z. To keep them in their unaccented puzzle
spelling, strip accents first:

```sh
python3 -c "import sys,unicodedata as u; [print(''.join(c for c in u.normalize('NFD',l) if not u.combining(c)),end='') for l in sys.stdin]" < wordlist.txt > dutch.txt
```

IJ is written as two letters, in two cells.

## Swedish

SALDO's full-form lexicon, Språkbanken Text, University of Gothenburg
(CC BY 4.0): <https://spraakbanken.gu.se/en/resources/saldom>. Download
`saldom.xml` (about 240 MB) from
<https://svn.spraakbanken.gu.se/sb-arkiv/pub/lmf/saldom/saldom.xml>, then
extract its written forms:

```sh
python3 scripts/extract_saldo_forms.py saldom.xml swedish.txt
```

The result has about 870,000 forms (lemmas and inflections), within the
import limits. Compound-only parts and multi-word entries are left out.

## Rebuilding the bundled letter models

The pattern checks and dictionary-free suggestions use the n-gram counts in
`app/models/`. Rebuild them from the same sources with:

```sh
python3 scripts/build_language_models.py --en /usr/share/dict/web2 \
    --fi nykysuomensanalista2024.txt --nl wordlist.txt --sv swedish.txt
```

Source credits are in [app/models/README.md](../app/models/README.md).
