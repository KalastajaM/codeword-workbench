The handles start on the grid border when it can be found. Check that the outline follows the border and drag any handle that is off. Where an edge curves, click the outline to add a point; double-click a point or press Delete to remove it. Arrow keys move a selected handle precisely.

Manual adjustments

Use these controls if the imported grid is misaligned or has the wrong dimensions. Alignment values are percentages of the full image.

To correct the dimensions, change Rows and Columns above, then apply them here.

After applying corrections, read the numbers and printed letters again. This replaces current grid entries.

Mapping & language rules

Optional: most puzzles need neither list. Use letters only, one sequence per line or separated by commas. Sequences match anywhere in a word; wildcards and regular expressions are not supported.

Dictionary

Plain text finds words that start with it. ? is exactly one letter and * is any number of letters, so K?TT* finds KATT and KATTEN, and *NING finds words ending in NING.

Changes in this list are saved immediately. Disabled words stay in the dictionary but are not used for solving, candidates or pattern search; enable them again at any time. Deleting removes a word from the list.

Bulk edit and import

Edit one word per line. Large lists are shown in pages of up to 1,000 lines. Edits on every page are saved together. Add words here or remove entries to exclude them. Choose a UTF-8 list, then Save dictionary to replace the active dictionary. Lists up to 16 MB and 1,000,000 entries are supported; invalid lines are skipped and reported.
